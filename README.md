# 🧾 Делим счёт

**Общие траты компании и минимум переводов, чтобы все были в расчёте.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/split-bill/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Деление поровну или точными суммами
- Баланс каждого участника
- Минимум переводов (жадный алгоритм)
- Итог для чата и ссылка на расчёт
- Работает без сервера

## Стек

JavaScript. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/split-bill.git
cd split-bill
python3 -m http.server 8000
```
